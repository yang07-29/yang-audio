## A 从频谱到特征
Mel 梅尔滤波器组按听觉启发的频率尺度汇聚能量。对结果取对数，得到 log-Mel 特征。对 log-Mel 再做离散余弦变换并保留部分系数，可得到常见 MFCC。

Mel 特征压缩了频率信息，通常不保留完整相位。它适合不少识别任务，但不能当作原波形的无损编码。

| 特征 | 常见用途 | 代价 |
|---|---|---|
| 原始波形 | 时域增强、分离、神经编码 | 序列很长 |
| 复数 STFT | 增强、滤波、阵列 | 需要处理幅度和相位 |
| log-Mel | ASR、事件检测、部分合成系统 | 不能直接无损还原 |
| MFCC | 传统识别、轻量模型 | 压缩更强，可能丢失有用细节 |
| 学习型表示 | 自监督、语音大模型 | 依赖训练数据与模型 |

## B 每种网络在音频里做什么
| 结构 | 直觉 | 常见问题 |
|---|---|---|
| CNN 卷积网络 | 找局部时间或频谱模式 | 感受野够不够，是否因果 |
| RNN/LSTM/GRU | 用状态记住历史 | 长序列训练与并行效率 |
| Transformer | 用注意力建立位置之间的关系 | 序列长度、内存、掩码和缓存 |
| Conformer | 结合卷积局部建模和注意力 | 块大小、位置编码、流式约束 |

Conformer 结合两类结构的设计见[原始论文](https://arxiv.org/abs/2005.08100)。选网络时先看任务、数据和延迟要求，不按名字新旧判断优劣。

缩放点积注意力可写为：

$$
\operatorname{Attention}(\mathbf Q,\mathbf K,\mathbf V)
=\operatorname{softmax}\!\left(\frac{\mathbf Q\mathbf K^{\mathsf T}}{\sqrt{d_k}}\right)\mathbf V
$$

$\mathbf Q$ 用来查询，$\mathbf K$ 用来匹配，$\mathbf V$ 提供汇总内容；$d_k>0$ 是查询和键的特征维数，softmax 沿键的位置维计算。因果任务还需在 softmax 前加入因果掩码，阻止使用未来信息。

## C 最小训练流程
```flow LR
数据清单 -> 数据加载: 读取、裁剪、变长补齐
数据加载 -> 模型预测: 记录张量形状
模型预测 -> 损失函数: 与监督目标比较
损失函数 -> 梯度更新: 反向传播与优化器
梯度更新 -> 验证评测: 不更新参数
```

训练集用于更新参数，验证集用于选配置，测试集用于最终报告。说话人、录音会话或噪声文件跨集合重叠，会使结果过于乐观。

训练模式和推理模式不同。验证时应切换 eval，并禁用梯度记录。填充部分要通过长度或掩码排除，防止污染损失和统计量。

## D 招聘中的 Python/PyTorch 到底要会什么
| 能力 | 具体任务 |
|---|---|
| 数组与张量 | 解释批次、通道、时间、频率四个轴 |
| 数据加载 | 批处理、变长补齐、随机裁剪、采样率检查 |
| 梯度 | 知道 zero_grad、backward、step 的作用 |
| 调试 | 检查 NaN、梯度、标签、学习率和数据泄漏 |
| 实验管理 | 固定种子、保存配置、记录版本与检查点 |
| 基础算法 | 数组、哈希、排序、二分、动态规划、复杂度 |

小数据过拟合测试很有用：如果连十条样本都学不会，先查实现和标签，再扩大数据规模。

## E 动手任务与损失选择
先实现“输入带噪幅度谱，输出频谱掩码”的小网络。目标是跑通数据、训练、验证、重建和试听，不要求从第一天获得最好指标。

增强可用波形损失、频谱损失或 SI-SDR 相关目标。分类常用交叉熵；序列识别可能用 CTC。损失与评价指标并非必须完全相同，但要解释二者的联系。

记录一个真正的失败：比如训练损失下降但新说话人效果变差。比较训练与验证数据分布，提出可检验原因。

## F 自测与答案
| 问题 | 答案 |
|---|---|
| 为什么不能把同一长录音随机切片后随意分训练测试？ | 相邻片段共享说话人、设备和背景，容易泄漏 |
| 为什么验证时关闭梯度还需要 eval？ | eval 还会切换 Dropout、BatchNorm 等模块行为 |
| 训练损失低就足以写“效果优秀”吗？ | 不够；需独立评测、基线和实验条件 |

## 特征是在保留与压缩之间取舍
| 表示 | 主要信息 |
|---|---|
| 波形 | 直接记录振幅序列 |
| 复数频谱 | 显示频率、幅度与相位 |
| 对数梅尔谱 | 汇聚频带并压缩动态范围 |
> 波形最直接，但时间序列可能很长。
> 频谱帮助我们定位不同频率的结构。
> 梅尔特征适合许多识别任务，却不是无损编码。
## 学习循环
```flow LR
输入与标签 -> 预测: 模型前向计算
预测 -> 损失: 衡量预测与目标差异
损失 -> 更新参数: 反向传播
```
> 先确保输入和标签是正确配对的。
> 损失告诉模型这次预测错了多少。
> 梯度指导参数更新，下一次再重新预测。
## 真正需要交付的能力
| 任务 | 能力证据 |
|---|---|
| 调试 | 能解释张量形状和错误来源 |
| 验证 | 在独立数据上比较基线 |
| 复现 | 配置、种子、代码与数据版本齐全 |
> 会运行示例以后，要继续练习定位错误。
> 训练集好不代表未知说话人也好。
> 别人能够重现实验，项目才容易被理解和认可。
