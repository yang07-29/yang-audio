## A 三种问题有什么区别
| 任务 | 干扰是什么 | 常见输出 |
|---|---|---|
| 降噪 | 环境或设备噪声 | 更干净的语音 |
| 去混响 | 同一声源的房间反射拖尾 | 更接近目标清晰度的语音 |
| 多说话人分离 | 同时讲话的不同人 | 每个人对应的一路音频 |
| 目标说话人提取 | 混合中的特定人 | 指定目标的一路音频 |

混响可写为 $y=h*s$，其中星号表示卷积；噪声通常建模为加性项。实际环境常二者都有。任务定义要说明保留直达声还是允许早期反射。

## B 房间冲激响应与去混响
房间冲激响应 RIR 包含直达声、早期反射和晚期混响。RT60 描述理想化的衰减时间尺度，不足以单独描述房间所有特性。

加权预测误差 WPE 在时频域用延迟的历史帧预测晚期混响，再从当前信号中减去。预测延迟用于尽量保留目标的早期部分。

网络去混响则从数据中学习恢复目标。模拟 RIR 与真实房间失配、移动说话人和通道变化，都会影响泛化。

## C 说话人分离与排列问题
假设混合 $y=s_1+s_2$，网络输出两路。输出第一路对应谁没有天然固定顺序。按固定顺序计算损失，可能把正确分离也当成错误。

排列不变训练 PIT 比较允许的输出—参考对应关系，选择总损失最小的排列。两人分离时，比较两种匹配；更多声源需要更高效的匹配策略。

Conv-TasNet 代表时域分离路线，SepFormer 代表基于注意力的分离路线。学习时关注编码器、长序列建模、掩码和重建；别只记模型名称。

## D 指定一个人时，如何给条件
```flow LR
目标参考语音 -> 说话人表示: 描述目标音色
混合语音 -> 提取网络: 包含多个声源
说话人表示 -> 提取网络: 指定想听谁
提取网络 -> 目标语音: 检验身份与内容
```

目标表示也可能来自视觉、方向或文字描述。不同条件对应不同假设；参考音频与测试混合不能重叠泄漏。

声纹相似不保证内容正确；分离指标高也不保证目标身份正确。需同时检查重叠区间、目标保持和非目标泄漏。

## E 指标与实验
SI-SDR 先把估计信号投影到参考信号方向，得到缩放后的目标，再比较目标投影与残差功率。它减弱整体增益差异影响，但不能替代对音量、感知质量和身份的评价。

SI-SDR 改善量是处理后分数减去混合输入的基线分数。报告时明确是否使用排列匹配，以及均值怎样计算。

项目可按“无混响二人混合→带混响混合→未知说话人”递进。模型算得快，不代表具备因果流式能力。

## F 自测与答案
| 问题 | 答案 |
|---|---|
| 去混响能简单归结为减噪声吗？ | 不能；反射与目标信号有关，通常是卷积失真 |
| 为什么两路输出对调仍可能完全正确？ | 分离目标本身不一定规定输出身份顺序 |
| 分离与说话人日志有什么区别？ | 分离输出波形；日志输出谁在什么时间讲话 |

## 先判断干扰的来源
| 干扰 | 对应任务 |
|---|---|
| 风扇声 | 降噪 |
| 墙壁反射拖尾 | 去混响 |
| 两个人同时讲话 | 说话人分离 |
> 不同任务有不同的观测模型。
> 房间反射不是独立于目标的普通背景噪声。
> 另一个人的语音又和目标具有类似结构。
## 输出顺序不固定怎么办
| 输出 | 匹配方案 |
|---|---|
| 第一路与第二路 | 分别对应甲和乙 |
| 第一路与第二路 | 分别对应乙和甲 |
| 训练损失 | 选择更合理的对应关系 |
> 网络可能先输出甲，也可能先输出乙。
> 只因顺序不同就惩罚它，并不合理。
> 排列不变训练把这个对应关系一起考虑。
## 如果我只想听一个人
```flow LR
参考语音 -> 目标身份表示: 告诉模型想听谁
混合语音 -> 目标提取: 结合条件
目标身份表示 -> 目标提取: 提供身份信息
```
> 先用参考片段描述目标说话人。
> 模型从混合声音中提取符合条件的部分。
> 评测时既要看内容质量，也要看提取的是否为目标本人。
