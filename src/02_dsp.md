## A 为什么要把声音变到频域
时域告诉你“什么时候变化”，频域告诉你“有哪些频率”。傅里叶变换把信号表示成不同频率的复指数之和。

DFT 是离散傅里叶变换；FFT 是高效计算 DFT 的算法。复数频谱的模表示幅度，角度表示相位。相位包含时序结构，不能默认无关紧要。

$N$ 点 DFT 的频率栅格间隔是 $\Delta f=\frac{f_s}{N}$，其中 $f_s$ 是采样率。零填充会加密栅格，但不会凭空增加观测时长或真正分开原本不可分辨的近频率。

## B 为什么分帧、加窗，再做短时傅里叶变换
语音随时间变化。短时傅里叶变换 STFT 用滑动窗口，分别观察一小段声音的频谱。

```flow LR
波形 -> 分帧: 截取短片段
分帧 -> 加窗: 减弱片段边缘突变
加窗 -> 快速傅里叶变换: 得到复数频谱
快速傅里叶变换 -> 声谱图: 时间与频率上的强度
```

16 kHz 下，25 ms 帧长为 400 点，10 ms 帧移为 160 点。FFT 长度可以设 512，实信号单边频谱有 257 个频率格。

较长窗口通常改善频率分辨能力，却模糊快速时间变化。较短窗口更善于观察瞬态，却更难分清接近的频率。

Hann 窗降低旁瓣泄漏，也会改变主瓣宽度。它没有同时消除所有代价。

## C 声谱图怎样读
横轴是时间，纵轴是频率，颜色通常表示对数幅度或功率。阅读前先看图例与单位。

浊音常出现谐波结构；基频 $F_0$ 与谐波间隔有关。共振峰来自声道共振，不能把共振峰等同于基频。

清辅音可能呈现宽带高频能量。噪声与语音会重叠，不能简单删掉所有高频或低能量区域。

STFT 逆变换用重叠相加重建波形。分析窗、合成窗、帧移与边界处理必须配合，否则可能产生幅度起伏和边缘误差。

## D 卷积就是系统对过去输入的加权叠加
$$
y[n]=\sum_k h[k]x[n-k]
$$

$x$ 是输入，$h$ 是冲激响应。房间反射、数字滤波器，都可在线性时不变等适用假设下用这个形式描述。

| 概念 | 作用 | 要注意什么 |
|---|---|---|
| FIR 有限冲激响应 | 用有限长度系数过滤信号 | 运算量与阶数；可设计线性相位 |
| IIR 无限冲激响应 | 使用历史输出递推 | 极点、稳定性与数值误差 |
| 相关 | 比较两信号在不同相对延迟下的相似性 | 与卷积的翻转、共轭和符号约定不同 |
| 自适应滤波 | 根据误差持续调整滤波器系数 | 步长、收敛、输入相关性 |

因果系统只能使用当前及过去输入。使用未来帧会增加等待时间，或令模型无法严格实时。

## E 动手任务
合成 440 Hz 与 1000 Hz 两种频率叠加的信号。改变观察长度，再比较频谱峰。

然后把一个短脉冲与三个非零抽头的 $h$ 卷积，观察多个延迟副本。运行配套 stft 模式，检查频谱形状与重建误差。

建议先能解释数组形状，再做网络。矩阵的时间轴与频率轴写反，会让模型沿错误方向卷积。

## F 自测与答案
| 问题 | 答案 |
|---|---|
| 16 kHz、512 点 FFT 的栅格间隔？ | 31.25 Hz，不等于任意两音调都能隔这么近分开 |
| 只看幅度谱就保留全部信息了吗？ | 没有；一般还缺相位 |
| 把 FFT 长度增加十倍一定提升真实分辨率吗？ | 不一定；零填充只加密频率采样 |

## 从声音到声谱图
```flow LR
波形 -> 分帧加窗: 观察短时间片段
分帧加窗 -> 频谱: 分析每段频率
频谱 -> 声谱图: 沿时间拼起来
```
> 一整句话不断变化，先切成短片段。
> 每个片段计算频谱，获得频率与相位信息。
> 把频谱沿时间排列，就能看到声音怎样变化。
## 三个参数
| 参数 | 决定什么 |
|---|---|
| 帧长 | 每次观察多长时间 |
| 帧移 | 多久更新一次观察 |
| 变换长度 | 频率格点的数量 |
> 帧长影响时间与频率之间的分辨权衡。
> 帧移更小，通常意味着更多重叠与计算。
> 零填充增加格点，但不会增加原信号信息。
## 滤波和房间都可以看成系统
```flow LR
输入声音 -> 冲激响应: 描述系统
冲激响应 -> 卷积输出: 过去输入的加权叠加
卷积输出 -> 检查: 频响、稳定性与时延
```
> 冲激响应描述一次短促激励之后，系统如何响应。
> 任意输入经过这样的系统，可以用卷积来计算。
> 音频算法既要看频谱效果，也要看时延和稳定性。
