> 先不要背复杂网络。今天我们追踪一段声音，看看它怎样变成算法能处理的数字。

## 声音进入电脑之前发生了什么
```flow
声源振动 -> 空气压力变化
空气压力变化 -> 麦克风电信号
麦克风电信号 -> 数字波形
数字波形 -> 声音信息: 保留时间与幅度
```
> 你说话时，声带和口腔共同影响空气压力。声音不是一条画在纸上的线，而是随时间变化的物理过程。
> [麦克风电信号]是传感器对压力变化的响应。它还会受到麦克风、距离和房间的影响。
> 电脑保存的[数字波形]，是一串按时间排列的数。横轴是时间，纵轴是相对于数字量程的幅度。
> 幅度大通常表示数字电平更高，但它不直接等于真实声压。录音设备的增益也会改变数值。
> 所以，先检查采样率、声道和幅度范围，再谈模型。把输入理解错，后面的复杂算法也救不了。

## 采样率和位深不是一回事
```tree
数字录音
  采样率：每秒取多少个时间点
  位深：每个幅度用多少等级表示
  声道：同时保存几路信号
  时长：每路样点数除以采样率
```
> 一秒十六千赫兹的单声道录音，每路有一万六千个样点。它们不是一万六千个频率。
> [采样率]决定时间轴取点密度。想表示更高频率，需要足够的采样率，并在采样前控制混叠。
> [位深]决定幅度量化精度。十六位不是每秒十六个样点，也不是十六个声道。
> [声道]表示同时记录的信号条数。双麦克风有两路；直接展平数组会把声道和时间错误混在一起。
> 重采样可以改变数字的采样网格，但不能恢复原录音已经丢失的高频信息。不要把插值当作无损升级。

## 分贝必须说清参考量
```tree
分贝阅读顺序
  先问：比较幅度还是功率
  再问：参考值是什么
  区分：数字满量程与物理声压
  检查：信号和噪声如何统计
```
> 分贝是比例的对数表达。单说一个分贝数字还不够，你要先知道它和什么比较。
> 幅度比与功率比使用不同系数。相同阻抗条件下，幅度翻倍约增加六分贝，功率翻倍约增加三分贝。
> 数字录音常用满量程作为参考。接近零分贝满量程，表示接近数字上限，不代表环境中没有声音。
> 信噪比比较信号功率和噪声功率。算之前要确定哪些样点是信号，哪些样点代表噪声。
> 如果只是把整段录音统一放大，信号和噪声一起变大，信噪比并不会因此改善。降噪不是单纯调音量。

## 为什么把长声音切成短帧
```flow
长波形 -> 重叠短帧: 分帧
重叠短帧 -> 加窗短帧: 平滑帧边界
加窗短帧 -> 复数频谱: 傅里叶变换
复数频谱 -> 时频图: 连续观察各帧
```
> 语音一直在变化。整段只算一次频谱，会把不同时间的发音混在一起，看不到变化发生在什么时候。
> 所以先取[重叠短帧]。窗长决定每次观察多长时间，帧移决定下一帧向前移动多少。
> [加窗短帧]让帧边界更平滑，减少截断造成的频谱泄漏。窗函数会改变权重，不是凭空增加信息。
> 傅里叶变换产生[复数频谱]，它同时包含幅度和相位。频谱图常显示幅度或功率，相位并没有不存在。
> 窗长和帧移是不同参数。零填充能让频率采样点更密，却不能替代更长观测带来的真实分辨能力。

## 从频谱到特征，再到任务
```flow
复数频谱 -> 幅度与相位
幅度与相位 -> 语音增强: 估计干净语音
复数频谱 -> Mel能量与对数: 压缩成声学特征
Mel能量与对数 -> 语音识别: 预测文字序列
```
> 不同任务选择不同表示。语音增强常需要保留可以重建波形的信息，识别则更关注与文字有关的线索。
> 增强模型可能预测掩码、频谱或波形。看项目时，要确认输出是什么，不能见到模型就假定它直接输出音频。
> [Mel能量与对数]把频率信息重新汇聚，再压缩动态范围。它不是把原始样点简单改个名字。
> [语音识别]还要处理对齐问题：很多时间帧对应较少的文字单元。特征帧数与输出字数通常不相等。
> 今天先记住波形、帧、频率格点和文字单元这四个对象。它们的长度不同，张量的轴也不能混用。

## 今天用一个小实验检查理解
```tree
今日验收
  写出一秒录音的样点数
  标注单声道数组的时间轴
  解释窗长和帧移
  区分降噪与统一放大
```
> 不需要今天就训练模型。先把一秒录音的样点数算对，再在代码里打印数组形状。
> 看波形图时，指出时间轴和幅度轴。看时频图时，指出时间、频率与颜色分别表示什么。
> 接着只改变一个参数，例如窗长，保存修改前后的图。用一句话描述看到了什么，不凭感觉宣布效果更好。
> 最后解释为什么统一放大不能提高信噪比。如果你能说清这件事，已经跨过了一个常见新手误区。
