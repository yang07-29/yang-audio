下面代码在生成本站时实际执行。这里只是教学小实验，不是完整模型训练或业务设备测评。

import numpy as np
fs, f0, nfft = 16000, 1000, 512
# 三毫秒波形：一千赫兹应出现三个周期
t = np.arange(48) / fs
wave = np.sin(2*np.pi*f0*t)
double = 2 * wave
rms = np.sqrt(np.mean(wave**2))
rms2 = np.sqrt(np.mean(double**2))
gain_db = 20*np.log10(rms2/rms)
print("10 ms 样点数", int(fs*0.01))
print("周期", 1000/f0, "ms；FFT 间距", fs/nfft, "Hz")
print("幅度翻倍的电平变化", round(gain_db, 2), "dB")
print("48 kHz 双声道 16 bit PCM", 48000*2*16//8, "字节/秒")

闭卷自测：16 kHz 的 1 kHz 正弦幅度翻倍后，每周期样点数与电平变化分别是什么？

仍为 16000/1000=16 点每周期，频率不变；同一参考下幅度电平增加 20log10(2)≈6.02 dB。

逐字讲稿 · 可定位回看

“16000、1000、0.5、2”看起来都是数字，但放在一条录音上可能分别指采样率、频率、数字幅度和秒数。不给单位，数字就没有完整含义。

一段单声道数组有 32000 点，采样率 16000 Hz，所以时长为 2 秒。 若它是 1000 Hz 的纯音，这 2 秒大约有 2000 个周期；周期数和采样点数显然不同。

峰值数字幅度为 0.5，只说明一种数值尺度下的最大摆动，不能直接读成“0.5 分贝”或真实环境的声压。 名字相似不代表任务相同。声纹验证不是识别文字，语音分离也不自动知道每一路说话人的真实身份。

这一课不是要你一口气记住所有缩写。我们只抓一段一千赫兹正弦，采样率一万六千赫兹，看看同一个数字在不同位置到底是什么意思。

读图或读代码时先问四个问题：这个对象是什么，横纵轴是什么，单位是什么，它服务于什么任务。很多看似深奥的错误，实际上是把两个不同对象的长度或单位混了。

你可以把本视频当闭卷检查：每道题先暂停预测，再看动画和结果。不懂时回到对应正文补前置概念，比继续背下一批模型名字更能形成稳定基础。

采样率一万六千表示每秒记录一万六千个样点。信号频率一千表示这个正弦每秒重复一千周期，两者都用赫兹，但一个数记录次数，一个数振动周期。

一万六千除以一千等于十六，所以每个周期有十六个采样位置。一千赫兹的周期是一毫秒，三毫秒里会出现三个周期，与声音幅度多大无关。

如果只改文件声明的采样率而不重采样，播放器会按另一节奏读同一组数字，时长和音调都可能变化。正确重采样则是重新计算新时间格点上的信号。

假设四万八千赫兹、双声道、每个样点十六位。一秒共有四万八千乘二个采样值，每个十六比特，再除以八，把比特换成字节。

结果是一秒十九万二千字节，没包括文件容器头。这里说的是未压缩 PCM，不能把同样公式直接当压缩音频的实际码率，压缩后的存储还取决于编码方式。

位深描述每个采样值可用多少位表示，码率描述每秒多少比特，采样率描述每秒多少点。看到一个数字先补完整单位，就能避免把高码率误认为高音调。

窗长决定一次截取多少样点，帧移决定相邻窗起点相差多少。它们可以不同，因此帧通常重叠。不能因为每十毫秒来一次结果，就断言窗也只有十毫秒。

一万六千赫兹下五百一十二点 FFT 的频率格点间距是一万六千除五百一十二，等于三十一点二五赫兹。这里的格点间距不要直接等同所有情况下的分辨能力。

给同一短窗补零，可以让显示的频率格点更密，但没有观察到更长的真实声音。窗函数和观测长度仍影响分开相近频率的能力，漂亮细曲线不等于新增信息。

对同一阻抗或同一信号尺度的比较，功率与幅度平方有关。幅度翻倍会让平方量变成四倍，所以电平增加十乘以四的对数，约六点零二分贝。

也可以直接用二十乘以幅度比二的对数，得到相同结果。功率只翻倍时才是约三点零一分贝，不能把两种翻倍混成同一句话。

零分贝表示某个比值为一或等于约定参考，不自动等于静音。零分贝信噪比表示信号和噪声能量相同；数字音频的零 dBFS 又涉及满量程参考。

时间轴用样点编号除采样率生成，四十八点对应三毫秒长度的采样片段。正弦频率一千，所以图中能看见三个周期，第二条线只是每个数乘二。

RMS 先平方、再平均、最后开方。两条线有完全相同的周期，幅度比为二，RMS 比也为二，所以二十倍对数得到六点零二分贝。

最后几行把十毫秒样点数、周期、FFT 格点和 PCM 数据量分别打印。它们来自不同公式，请检查每个单位；这不是校准过的真实声压级或主观响度测试。

两条曲线的波峰出现在相同时间，过零位置也相同。第二条更高、更低，但没有横向压缩，所以周期仍是一毫秒，不是音高提高了一倍。

实际输出显示十毫秒为一百六十点，FFT 间距三十一点二五赫兹，幅度电平增加约六点零二分贝。每个结果都能用前面单位关系独立复算。

这段合成波形幅度翻倍后超过正负一，是数学数组允许的。若保存为受限音频格式，要检查缩放和削波，不能直接认为所有播放链路都能原样容纳这些数值。

VAD 判断何时有语音，不识别说了什么。ASR 输出文字，不自动确认人物身份。TTS 从文本条件产生声音，好听也不代表每个字都生成正确。

AEC 利用已知播放参考估计回声再抑制，不等于主动噪声控制 ANC；后者需要扬声器产生实际反向控制声场。把文件降噪叫主动消声，会混淆物理系统。

声纹比较声音身份特征，日志标记谁在何时说，分离则输出不同声源波形。选指标前先写输出类型，文字错字率、身份误接受率和日志时间错误不能互相替代。

两声道分别能听见，平均后近乎没声，先看极性或相位是否相反。离线正常而分块咔哒响，先查滤波状态和重叠相加，不要立刻断言模型太小。

训练损失很低，换一个人失败，先查数据划分与分布差异。降噪后安静但识别更差，可能伤到辅音尾音或改变输入分布，需要同时看语音保真和文字错误。

一分钟声音处理三十秒，RTF 是零点五，只说明平均计算速度。若先等整分钟录完，首包仍很晚；因果不使用未来，也不等于没有凑帧和排队等待。

请闭卷回答：十六千赫兹下十毫秒多少点？一百六十。幅度翻倍增加多少分贝？同一参考下约六点零二。RTF 零点五能保证首字很快吗？不能。

每次错题只写四行，原想法、实际现象、正确解释、下次检查。比如我以为曲线更高就是音调更高，实际峰的位置没变，所以那是幅度变化。

复习验收不要问自己看过没有，而是拿出一张没有标题的图，解释轴和单位，指出对应代码，再说一个结论不成立的条件。这才是面试时能真正用出来的理解。

样点数除采样率得到秒；二百五十六点在一万六千赫兹下是十六毫秒。帧索引乘hop得到名义时间位置，还要考虑填充、窗口中心和边界约定。

特征帧经过模型下采样以后，输出步数可能更少。不能把输入每十毫秒一帧，直接推成输出每个token对应十毫秒。具体时间戳要看模型接口与导出约定。

音频token也不必等于文字token。压缩码本索引、识别字符和大模型词片是不同表示，计算码率、序列长度和延迟时需要分别标注。

先问输入是什么、输出是什么，便能区分增强、分离、识别、合成和说话人任务。再问它是训练方法、网络结构、损失、指标，还是工程接口，避免把不同层次的缩写并排比较。

第三问需要什么数据和假设：是否有干净参考、是否允许未来信息、是否需要校准、是否固定声源数量。没有前提的公式很容易被套错场景。

最后问怎样跑出最小结果、失败时怎么看。保留一个四点手算、一个可运行例程和一张实际图，比只收藏定义更容易形成可迁移的理解。

这是随用随查的附录，不是另一套从头开始的课程。先在正文遇到概念，再回来核对一句话定义；下面的自测按“单位→代码→任务评价”逐步检查，不需要第一次就全部通过。

名词：采样率 sample rate。用一句话解释：一秒记录多少个离散样本。不等于什么：不等于音调频率。

名词：位深 bit depth。用一句话解释：一个采样值可用多少位表示。不等于什么：不等于压缩码率。

名词：码率 bitrate。用一句话解释：每秒存储或传输多少比特。不等于什么：不等于采样率。

名词：帧 frame。用一句话解释：为局部处理截取的一小段。不等于什么：不必是不重叠片段。

名词：帧移 hop。用一句话解释：相邻帧起点间隔。不等于什么：不等于窗长。

名词：频谱 spectrum。用一句话解释：不同频率成分的表示。不等于什么：单张整段频谱没有时间定位。

名词：声谱图 spectrogram。用一句话解释：短时频谱沿时间排起来。不等于什么：颜色不一定是校准声压。

名词：相位 phase。用一句话解释：周期位置或频域角度关系。不等于什么：不可随意丢掉后期待无损重建。

名词：FIR。用一句话解释：输出由有限个输入历史加权形成。不等于什么：不是所有FIR都是线性相位。

名词：IIR。用一句话解释：具有反馈的常见递归滤波实现。不等于什么：不代表一定不稳定。

名词：因果 causal。用一句话解释：输出不使用未来输入。不等于什么：不代表没有等待时间。

名词：AEC。用一句话解释：减去来自已知参考的回声估计。不等于什么：不是物理主动消声。

名词：ANS/NS。用一句话解释：抑制不需要的噪声成分。不等于什么：不保证识别准确率一定提高。

名词：AGC。用一句话解释：调节电平与动态变化。不等于什么：不是把噪声变成语音。

名词：VAD。用一句话解释：判断何时有语音活动。不等于什么：不是识别说了什么。

名词：KWS。用一句话解释：检测关键词或唤醒词。不等于什么：不等于完整ASR。

名词：ANC。用一句话解释：控制扬声器产生声音以降低某位置噪声。不等于什么：不是只对文件做数字降噪。

名词：ASR。用一句话解释：声音到文字。不等于什么：不自动知道说话人身份。

名词：TTS。用一句话解释：文字条件下生成语音。不等于什么：好听不代表内容一定正确。

名词：声纹验证。用一句话解释：判断两段声音是否来自同一人。不等于什么：不等于转写。

名词：说话人日志 diarization。用一句话解释：谁在什么时候说话。不等于什么：聚类标签未必是真实姓名。

名词：Mel。用一句话解释：一种非线性频率刻度及其滤波表示。不等于什么：不是某个神经网络。

名词：MFCC。用一句话解释：通常对对数Mel滤波器组能量做离散余弦变换，再选取系数得到的特征。不等于什么：系数轴不是频率轴。

名词：F0。用一句话解释：周期性声源的基频估计。不等于什么：不等于共振峰。

名词：共振峰 formant。用一句话解释：声道共振造成的谱包络峰。不等于什么：不一定落在某个单独谐波频点。

名词：batch。用一句话解释：一次送入模型的一组样本。不等于什么：不等于epoch。

名词：epoch。用一句话解释：一轮训练数据遍历的常用计数。不等于什么：不代表准确率提高一次。

名词：梯度 gradient。用一句话解释：损失对参数变化的局部敏感度。不等于什么：不保证一次更新就到最优。

名词：CTC blank。用一句话解释：对齐机制中的空白符号。不等于什么：不简单等于静音声音。

名词：CER / WER。用一句话解释：编辑错误数除以参考字符数 / 词数。不等于什么：不应混用计数单位；插入多时可超过100%。

名词：EER。用一句话解释：扫描阈值时误接受率与误拒率相等或按约定近似相等的错误率。不等于什么：不等于上线固定阈值的实际错误率。

名词：DER。用一句话解释：按协议统计的说话人漏检、误检与混淆时间之和，除以参考说话人时间。不等于什么：不等于转写错字率。

名词：RTF。用一句话解释：处理耗时除以音频时长。不等于什么：不足以描述首包与排队。

名词：首包延迟。用一句话解释：从明确约定的输入事件到首个可用输出的等待。不等于什么：不等于整句耗时；收到音频包也不等于已播放。

名词：P95 延迟。用一句话解释：延迟的第95百分位。不等于什么：不是最慢5%样本的平均延迟。 名词：RT60。用一句话解释：能量衰减60 dB的混响时间描述。不等于什么：不是最后非零样本时间。

1. 48 kHz、双声道、16位PCM，一秒裸数据多少字节？答案：（48000乘2乘16）除以（8）=192000 字节，不包含容器头。 2. 16 kHz下10毫秒有多少点？答案：160点。若计算得到160000，多半把毫秒当秒。 3. 频率1000 Hz，周期多少毫秒？答案：1毫秒。

振幅变化不会直接改变这个周期。 4. 同一参考下功率翻倍，增加多少dB？答案：10以十为底的对数(2)约等于3.01 dB；幅度翻倍对应功率四倍，约6.02 dB。 5. 一分钟音频处理用了30秒，RTF是多少？答案：0.5。但若等完整一分钟录完才开始，用户仍要等很久。

6. 16 kHz采样，512点FFT的格点间距是多少？答案：31.25 Hz。补零使格点更密不等于增加了观测时长。

情景一：两声道分别都能听见，平均后几乎没声。 先检查极性与相位，尤其是否一边约等于另一边的负值；不要直接说“平均融合算法不行”。

情景二：离线处理正常，实时每10毫秒出现咔哒声。 检查滤波状态、重叠相加、增益平滑和块长度处理。第03练习本有实际边界错误图。

情景三：训练损失很低，换个人就失败。 检查说话人划分和分布差异；训练集成绩不是泛化成绩。增加层数不是唯一办法。

情景四：降噪后更安静，但ASR错字更多。 可能损伤了辅音、尾音或相位结构，或前处理与识别训练分布不匹配。同时看听感、波形、识别错误类别，不只看噪声能量。

情景五：TTS把“2027”读得不合语境。 检查文本规范化与上下文：年份、编号、金额的读法不同。声码器并不直接负责选择年份读法。

情景六：波束形成角度完全反了。 先检查坐标、通道顺序、互相关定义、时延符号、角度相对阵列轴还是法线，不要先断言模型失效。

每次只写四行：我原来怎么想；运行或查证看到什么；正确解释；下次怎样检查。例：“我以为把音频除以最大值就总能公平比较；

实际上每段独立归一化改变了录音电平关系；评价时必须先定义协议；之后在配置里记录缩放策略。”

复习时不问“这章我看过没有”，而问“我能不用答案解释一张图吗”。先用两句话解释现象，再补公式，再指出代码中对应哪一行。最后能讲出一个失败条件，才算把知识从记忆变成了可使用的能力。
