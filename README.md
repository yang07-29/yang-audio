# yang-audio · 音频与语音算法学习站

在线学习入口：**https://yang07-29.github.io/yang-audio/**

此仓库是经授权公开的完整静态课程发布版：101 个 HTML 页面，包含连续教程、三个项目讲解、中文有声动画、可视化实验，以及 11 周 / 77 天学习计划。历史课程内容继续保留。

## 阅读与进度

- 直接访问在线入口，不需要安装 Python 或登录 ChatGPT。
- 每日任务、打卡、笔记与 90/120/150 分钟档位由浏览器本地保存，不上传至服务器。
- 不同网站、设备和浏览器不会自动同步进度。迁移时请在旧站的学习计划页导出进度 JSON，再在新站导入；关闭浏览器隐私模式或清理站点数据可能丢失本地记录。
- 中文有声动画需要用户点击播放；部分页面含内嵌音频，手机首次加载可能较慢。
- 文中的 `F:/codex/调研`、`C:/Users/yang` 等是作者本机路径示例，运行代码时请替换成自己的路径。

## 公开范围与发布

网站中的项目代码片段、结构和结果随本课程公开，原来三个 GitHub 项目仓库的隐私设置没有改变。私有仓库链接只对获授权账号可见，但页面里的教学内容可以独立阅读。

这是静态发布快照，不包含全部本机渲染器、生成脚本或训练环境；下方历史说明里的重建命令只适用于原始开发目录。教学算例、项目已有报告和实测证据的边界保留在对应章节中，不代表本次重新训练或业务测试。

GitHub Pages 发布源为 `main` 分支根目录，`.nojekyll` 用于保留原样静态资源。旧 ChatGPT Site 暂时保留。

## 实战实验

本机已验证 NumPy 2.4.4、SciPy 1.16.3、Matplotlib 3.10.6、PyTorch 2.11.0+cu128，实际使用 CPU。没有安装软件或下载预训练权重。

在课程根目录中依次运行：

```text
python code/run_experiments.py
python code/features_lab.py
python code/neural_lab.py
python code/anc_lab.py
python code/check_project_tools.py
python code/asr_evaluate.py results/asr_reference.jsonl results/asr_prediction.jsonl
```

也可运行 `python verify_practical.py` 一次完成上述实验、源码语法检查与发布页面检查，结果写入 `results/practical_verification.json`。实验会更新本课程内的生成图、音频、日志与教学权重；修改实验前可另存结果。

只检查发布页面、代码语法和已有实验记录，可使用 `python verify_practical.py --static-only`。完整复跑为每个子实验设置 180 秒超时，速度较慢的机器可调整此限制。

绘图脚本使用 Windows 微软雅黑字体。其他系统需替换为可用中文字体。阅读生成好的 HTML 不需要 Python；重建页面才需要本机所列 Node 与 am 路径，在其他机器重建需修改脚本路径。

## 证据边界

- DSP 使用合成信号；AEC 的双讲冻结对照使用已知真值，ANC 使用已知次级路径，不等于真实设备性能。
- 小型掩码网络确实训练了 16 轮，但输入是合成谐波和噪声，不是真实语音。
- ASR 提供 CTC 数值/梯度验证和可复用 CER 评测器。JSONL 示例是人工构造，不是模型识别结果。
- TTS 提供时长展开、教学声源滤波音频、声码器形状和梯度检查，没有训练自然语音合成系统。
- 量化是数值模拟，不代表推理后端实际加速；打断代码验证状态，不控制真实播放设备。
- 招聘样本用于对应技能，不保证当前招聘名额，也不能证明具体薪资。

课程实验可以如实写为学习实验。真实项目还需合规数据、训练/验证/测试划分、固定评测、基线对比、失败样例和个人贡献记录，参见实战 13。

只需 NumPy，运行 `python exercises/audio_basics.py all`。
四个实验分别验证指定信噪比、STFT 重建、理想 NLMS 路径估计、CTC 折叠与编辑距离。
本机已经运行并通过数值自检；详细结果见 `实验核验记录.md`。

实验采用合成数据，没有训练语音识别或语音合成模型，不把玩具实验成绩当成实际业务成绩。
